# stls について
アストロラーベのstlデータです
hari.stl
onigiri.stl
mainDisk.stl
backLine.stl
motite.stl

# 星図用 について
星図のsvgファイルとそれを描画するのに使用したc++のファイルがあります.
微調整をしていただいて，A4で印刷をします.
starMap.svg は緯度36度で描画してあります. もし変えたければ，
plot.cpp をお気に入りのエディタで開き，最初の部分を編集します.

```plot.cpp
7  #define RADIUS 169
8  #define LATITUDE 36
9  #define LIMIT_MAG 5.5
10 #define MARKER_SIZE 2.0
11 #define HOSEI 0.4
12 #define SVG_STEP 5
```
 
それぞれ，
星図の最終的な直径
観測地点の緯度
限界等級
補正値 *0にすると完全なステレオ投影，1にすると赤緯をそのまま中心からの距離にしたもにになります. 0.4ぐらいがいいとこどりな感じとおもいます*
描画精度

となっています.

保存後，gccなどでコンパイルして実行すれば，starMap.svgが上書きされます.
また，緯度を変更し，それをアストロラーベに使う場合，backLine.stl (経緯度線)
も変更する必要があります. line.cppを同様に変更してコンパイル，実行すると，
svgファイルが出力されるのですが，それを3Dデータにするのに苦労するかもしれません.
書くのも面倒なので，それを行なう場合は連絡をください.
(コンパイルについては調べればすぐに出てくるはずです)

# 使用方法
・測定
 ネジを適切な締めつけにして，( 指で軽く動かせるが，自重では動かないギリギリ ) 針の2つの穴と天体が1直線になるように，目標の天体にあわせます.
 あわせたら目盛を読みます. これで天体の高度が計測できます.

・予測
 裏の星図を使います. backLine の目盛 ( 1周24時間 ***反時計周り*** 丸がついている目盛が0時 ) と，mainDiskの側面の目盛 ( 1周1年 )をあわせます
 結果，backLine の(ほぼ)円になっている部分が現在の空です。(丸がついている目盛の逆側 回転の中心が天の北極 )
 線は軽度緯度ともに15°刻みになっっています. (天頂と真下付近を除く) 
 それをもとに高度を読みとり，針をその高度にあわせ，ナットを測定のときより少しきつく締めます.
 針の2つの穴を通して見た先に天体があるはずです *この作業はまだやったことがありません. もしかしたら星図がそれほど正確ではなくずれがあるかもしれません. あまりにずれていたら報告をよろしくおねがいします

 ・星図について
  以下，星図の等級とそれを表わすマーカーです.

 
  マーカー     | 視等級 
  ーーーーーーーーーーーーーー
     ◎         |     ~ 1.5
     ○         | 1.5 ~ 2.5
     ⬤         | 2.5 ~ 3.5
     ●(小さい方| 3.5 ~ 4.5
     ・        | 4.5 ~ 

  また，星図中にひかれている赤い線は黄道で，中央から引かれている線は月の初めの太陽の位置です. 薄明時刻予測にお使いください.

  星図の向きとしては，縦線 ( 冬，夏の星座を通っている方 ) の夏の星座がわを mainDisk の持ち手がわにあわせると，目盛通りになります.
  また，星図を印刷後，切りとる必要があると思いますが，アストロラーベより少し内側かつ星図が描かれている部分の外側 で切断すると引っかかりがなくスムースに動かせると思います.
